# Домашнее задание к занятию 11 «TeamCity»

**Выполнил:** Овсянников Сергей

## Основная часть

- [x] Создайте новый проект в TeamCity на основе форка.
- [x] Выполните автоматическое определение конфигурации.
- [x] Сохраните необходимые шаги, запустите первую сборку master.
- [x] Измените условия сборки: если сборка выполняется в ветке master, то должно выполняться `mvn clean deploy`, иначе `mvn clean test`.
- [x] Для развертывания необходимо загрузить `settings.xml` в набор конфигураций Maven в TeamCity, предварительно записав туда учетные данные для подключения к Nexus.
- [x] В `pom.xml` необходимо изменить ссылки на репозиторий и Nexus.
- [x] Запустите сборку из ветки master, убедитесь, что все прошло успешно и артефакт появился в nexus.
- [x] Мигрируйте build configuration в репозиторий.
- [x] Создайте отдельную ветку `feature/add_reply` в репозитории.
- [x] Напишите новый метод для класса Welcomer: метод должен возвращать произвольную реплику, содержащую слово hunter.
- [x] Дополните тест для нового метода на поиск слова hunter в новой реплике.
- [x] Сделайте push всех изменений в новую ветку репозитория.
- [x] Убедитесь, что сборка самостоятельно запустилась, тесты прошли успешно.
- [x] Внесите изменения из произвольной ветки `feature/add_reply` в master через Merge.
- [x] Убедитесь, что нет собранного артефакта в сборке по ветке master.
- [x] Настройте конфигурацию так, чтобы она собирала .jar в артефакты сборки.
- [x] Проведите повторную сборку мастера, убедитесь, что сбора прошла успешно и артефакты собраны.
- [x] Убедитесь, что конфигурация в репозитории содержит все настройки конфигурации из TeamCity.

**Ссылка на репозиторий:** https://github.com/sergey-281296/example-teamcity
